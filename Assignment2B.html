Metrics for .5

prediction_results <- prediction_results |>
  mutate(
    TP = sex == "female" & pred_05 == 1,
    FP = sex == "male" & pred_05 == 1,
    TN = sex == "male" & pred_05 == 0,
    FN = sex == "female" & pred_05 == 0
  )

metrics_05 <- prediction_results |>
  summarize(
    TP = sum(TP),
    FP = sum(FP),
    TN = sum(TN),
    FN = sum(FN)
  ) |>
  mutate(
    accuracy = (TP + TN) / (TP + FP + TN + FN),
    precision = TP / (TP + FP),
    recall = TP / (TP + FN),
    f1 = 2 * precision * recall / (precision + recall)
  )

Conclusion

The different probability thresholds affected the results. At 0.2 , the model had the highest recall (94.9%), correctly identifying the largest proportion of actual females, but it also had more false positives and lower precision (86.0%). At 0.5, precision and recall were both 92.3%. At 0.8, the model had the highest accuracy (94.6%), precision (94.7%), and F1 score (93.5%). Overall, the 0.8 threshold provided the best overall performance.
